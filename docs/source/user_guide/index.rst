User Guide
==========

The user guide is the conceptual companion to the tutorial notebooks. It keeps
reference tables and design explanations in one place, while the notebooks show
complete runnable workflows with project setup, jobs, results, and plots.

When a term such as :term:`EPW`, :term:`PML`, :term:`DAS`, or :term:`RTM` is
unfamiliar, check the :doc:`../glossary`.
