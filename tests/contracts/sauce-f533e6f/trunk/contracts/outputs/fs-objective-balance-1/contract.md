# FS Objective Balance Contract v1

Status: initial
Visibility: public
Contract id: `fs-objective-balance-1`

This artifact records positive componentwise comparison-space scales computed
from a nominated baseline residual before robust weighting. The reference-model
fingerprint is provenance and is not required to match later models. All data,
acquisition, source-signature, preprocessing, comparison, frequency, component,
dimension, and unit metadata must remain compatible when the scales are reused.

Sauce never updates these scales during objective evaluation or differentiation.
