# fs-control-mesh-adaptation-result-1

A completed stage setup returns the source-state identity, averaging window
fraction, resolved per-material half-widths in metres, and a mapping from requested
property-space names to immutable artifact paths. The native coefficient output
is named by the input job's `control_sensitivities.gradient`; its `/control_spaces`
identities match those artifacts. Zero radii denote layers without physical roots.
